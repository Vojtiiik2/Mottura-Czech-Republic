# Mottura Czech Republic

Statický web připravený pro GitHub Pages.

## Struktura

- `index.html` — hlavní HTML
- `style.css` — vzhled webu
- `app.js` — produkty, katalogy, modální detail a animace hero fotek
- `assets/img/logo/` — logo
- `assets/img/hero/` — tři hlavní náhledové fotky pro hero slideshow
- `assets/img/` — produktové náhledy
- `assets/catalogs/` — PDF katalogy Mottura

## Nahrání na GitHub

Rozbal ZIP a do repozitáře nahraj přímo tyto soubory a složky:

- `index.html`
- `style.css`
- `app.js`
- `assets/`

Nenahrávej samotný ZIP.

## Údržba kódu

Zdrojové soubory používají jednotné odsazení dvěma mezerami, UTF-8 a LF konce řádků. Pravidla jsou uložená v `.editorconfig`. HTML, CSS, JavaScript a Markdown jsou formátované pomocí Prettier 3.3.3.
