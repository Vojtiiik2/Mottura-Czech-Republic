# Mottura Czech Republic – statický web

## Jak nahrát na GitHub
1. Obsah této složky nahrajte do repozitáře.
2. V GitHub Pages nastavte branch `main` a root složku.
3. Produkty se upravují v `app.js` v poli `products`.
4. Katalogy nahrajte do `assets/catalogs` a upravte odkazy v poli `catalogues`.
5. Obrázky produktů nahraďte skutečnými fotkami od Mottury ve složce `assets/img`.

## Struktura
- `index.html` – obsah webu
- `style.css` – vzhled a responzivita
- `app.js` – produkty, katalogy, mobilní menu, animace
- `assets/img` – obrázky
- `assets/catalogs` – PDF katalogy
